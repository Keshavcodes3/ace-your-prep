# 📖 Overview

Ace Your Prep is a **Duolingo-inspired learning platform** that helps students master **Aptitude & Logical Reasoning** through bite-sized interactive lessons, gamification, adaptive practice, and performance analytics.

Instead of dumping thousands of MCQs on users, Ace Your Prep teaches **how to think** before asking users to solve questions.

The goal is to transform competitive exam preparation into an engaging, rewarding, and personalized experience.

# 💡 Core Principles

- Learning should feel like playing.
- Teach concepts before testing.
- Celebrate every small achievement.
- Build consistency, not cramming.
- Keep lessons short and engaging.
- Personalize the learning journey.
- Design for dopamine, but optimize for real understanding.
